## 🧩 About

**Black Squad Tool** is a lightweight overlay utility for the Steam PC version of Black Squad, adding an in-game menu with HUD tweaks, config profiles, sensitivity presets, and quality-of-life gameplay helpers.

Built for desktop use on Windows and intended to run alongside the game client.

---

## ✨ Features

### 🎮 Overlay Menu
- In-game overlay — toggle a compact menu on top of the game
- Hotkey control — open and close the menu without alt-tabbing
- Session info — quick readout of FPS and basic stats
- Preset switcher — jump between saved setups instantly

### 🎨 HUD & Display
- HUD tweaks — adjust on-screen element visibility
- Crosshair helper — customize a simple on-screen crosshair
- FOV tweak — adjust the field of view for a wider look
- Color profiles — save display presets per monitor

### 🏋️ Config & Training
- Config profiles — save and load multiple settings sets
- Sensitivity presets — quick DPI and in-game sens pairing
- Practice presets — local warm-up setups for offline play
- Backup & restore — export configs before changing them
